Overview

项目概述

错题管理系统是一个全栈智能错题管理平台。用户通过拍照或上传错题图片，系统利用 PaddleOCR PP-StructureV3 进行版面分析和文字识别，自动将错题内容转化为结构化 Markdown 文档，支持分类、标签、检索和批量导出，帮助学生和教师高效管理错题资源。

📸

Architecture

技术架构

后端采用 FastAPI 异步框架，OCR 引擎基于 PaddleX 实现，前端提供 PyQt6 和 Tauri v2 两种客户端方案。

层级技术选型说明
后端框架FastAPI + Uvicorn异步 RESTful API，自动生成 Swagger 文档
ORMSQLAlchemy 2.0声明式模型，支持 SQLite / MySQL 切换
OCR 引擎PaddleOCR + PaddleXPP-StructureV3 版面分析 + PP-OCRv5 识别
VL 增强PaddleOCR-VL-1.6通过 llama.cpp 运行的多模态大模型辅助识别
图像处理OpenCV + Pillow区域遮罩、版面可视化
桌面客户端 APyQt6原生 Python GUI，三标签页界面
桌面客户端 BTauri v2 + Vanilla JSRust 驱动，WebView2 渲染，NSIS 打包
日志Loguru结构化日志，支持文件轮转
配置管理pydantic-settings环境变量 + .env 文件
Quick Start

快速开始

以下步骤帮助你在本地快速启动错题管理系统：

1. 克隆项目

git clone <repository-url>
cd CUOTI_Lingma

2. 启动后端服务

cd backend
pip install -r requirements.txt
cp .env.example .env          # 编辑 .env 配置数据库连接
python -m app.main            # 默认端口 8100

3. 启动桌面客户端

# 方式 A: PyQt6 客户端
cd frontend
pip install -r requirements.txt
python main.py

# 方式 B: Tauri 客户端 (需要 Node.js + Rust)
cd APP
npm install
npm run tauri dev

4. 访问 API 文档

启动后端后，打开浏览器访问 http://localhost:8100/docs 查看 Swagger API 文档。

FAQ

常见问题

错题管理系统支持哪些图片格式？
支持 JPG、PNG、BMP、TIFF、WEBP 格式，单文件大小限制 10MB。建议使用清晰的照片或扫描件以获得最佳 OCR 识别效果。
OCR 识别需要联网吗？
不需要。PaddleOCR 引擎完全在本地运行，所有模型文件在首次使用时自动下载到本地。VL 增强模式可选启用，需额外下载 VL-1.6 模型。
支持哪些导出格式？
支持 Markdown (.md)、PDF (.pdf) 和 ZIP 归档三种导出格式。可以单题导出，也可以批量合并导出，方便打印和分享。
如何切换 PyQt6 和 Tauri 客户端？
两个客户端共享同一个后端 API。PyQt6 客户端通过 frontend/ 目录启动，Tauri 客户端通过 APP/ 目录启动。你可以根据使用习惯选择任一客户端。
数据库能切换到 MySQL 吗？
可以。在 .env 文件中修改 DATABASE_URL 为 MySQL 连接字符串即可。SQLAlchemy 会自动适配，无需修改代码。默认使用 SQLite 便于开箱即用。
项目使用什么许可证？
