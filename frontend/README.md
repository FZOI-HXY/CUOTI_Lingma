# 错题管理系统 - PyQt6客户端

基于PyQt6的桌面图形化应用程序。

## 功能特性

- 📤 图片上传和OCR处理
- 📚 错题管理和查看
- 📊 实时系统监控
- ⚙️ 可视化配置界面
- 🔄 自动刷新和状态同步

## 界面组件

### 上传处理面板
- 文件选择和预览
- 实时进度显示
- OCR结果展示
- 结果保存功能

### 错题管理器
- 错题列表浏览
- 筛选和搜索
- 查看详情
- 删除管理

### 系统监控
- CPU/内存/磁盘监控
- 处理统计
- 状态分布
- 自动刷新

### 配置对话框
- 后端地址配置
- API参数设置
- 文件大小限制
- 日志级别调整

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动应用

```bash
python main.py
```

## 配置

首次运行时会自动创建配置文件,位于:
- Windows: `C:\Users\<用户名>\.cuoti_system\config.json`
- Linux/macOS: `~/.cuoti_system/config.json`

## 注意事项

1. 确保后端服务已启动
2. 检查网络连接
3. 配置文件路径权限
