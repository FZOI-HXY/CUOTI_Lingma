## 💡 使用技巧

### 启动系统

```bash
.\start.bat
```

**会发生什么:**
1. 自动检查所有依赖
2. 如有需要,自动初始化数据库
3. 启动后端API (新窗口)
4. 启动前端GUI (新窗口)
5. 显示访问地址和帮助信息

### 停止服务

```bash
.\stop.bat
```

**功能:**
- 列出所有Python进程
- 确认后停止所有进程
- 检查端口是否释放

### 查看状态

```bash
.\status.bat
```

**显示:**
- Python环境状态
- 运行中的进程
- 端口占用情况
- 后端服务响应

### 系统诊断

```bash
.\diagnose.bat
```

**详细检查:**
- 所有关键文件
- Python版本
- 数据库连接
- 端口状态

## ❓ 常见问题

### Q1: 提示"系统找不到指定的路径"?

**A:** 新版本已完全修复此问题!所有路径都使用绝对路径。

如果仍有问题,请运行:
```bash
.\diagnose.bat
```
检查系统配置。

### Q2: 端口8000被占用怎么办?

**A:** 启动脚本会自动检测并提供两个选项:
1. 自动停止占用进程(推荐)
2. 取消启动,手动处理

或者先运行:
```bash
.\stop.bat
```
然后再启动。

### Q3: 如何从其他目录启动?

**A:** 完全可以!新版本支持从任何目录启动:

```bash
# 从桌面
C:\Users\YourName\Desktop> F:\CUOTI_Lingma\start.bat

# 从D盘
D:\> F:\CUOTI_Lingma\start.bat
```

### Q4: 启动后看不到窗口?

**A:** 检查任务栏,应该会看到:
- "后端服务 - FastAPI" 窗口
- "前端应用 - PyQt6" 窗口

如果最小化了,点击恢复即可。

### Q5: 如何只启动后端或前端?

**A:** 当前版本设计为同时启动。如需单独启动:

**仅后端:**
```bash
cd backend
..\venv312\Scripts\python.exe -m app.main
```

**仅前端:**
```bash
cd frontend
..\venv312\Scripts\python.exe main.py
```

### Q6: 数据库未初始化?

**A:** 启动脚本会自动检测并初始化数据库。

如需手动初始化:
```bash
.\venv312\Scripts\python.exe scripts\init_db.py
```
